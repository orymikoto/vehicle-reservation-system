# UI Guidelines

## Design Philosophy

The application should feel like an enterprise internal product designed by an experienced product team—not a trendy dashboard template.

The visual language should communicate:

- clarity
- confidence
- professionalism
- efficiency

Avoid interfaces that look generated by AI or assembled from generic Tailwind component libraries.

The UI should resemble modern enterprise products rather than startup landing pages.

Inspiration:

- Linear
- Stripe Dashboard
- GitHub
- Notion
- Vercel
- The attached ZeBeyond case study layout (adapted to a light theme)

Do NOT copy the visual design directly.

# Things to Avoid

Never use:

- Glassmorphism
- Heavy gradients
- Neon effects
- Blue hero gradients
- Floating blobs
- Huge border radius
- Random colorful cards
- Oversized icons
- Dashboard templates copied from Tailwind examples
- Material Design look
- Bootstrap appearance

The interface should feel timeless and enterprise-ready.
